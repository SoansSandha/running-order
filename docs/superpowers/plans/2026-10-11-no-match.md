# No Match Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner can mark an unmatched song as not on the other service. A marked song leaves the unmatched groups, is never searched for again, and is listed under "Not on the other service" with Undo.

**Architecture:**
- **A mark is a one-sided decision** in the existing match book: `{ spotifyKey, youtubeVideoId: null, verdict: 'none' }` or the reverse.
- **A new pure step, `setAsideMarked`,** runs between `settlePairs` and `settleFound`. It moves marked leftovers into their own lists, so no find is proposed for them. The sweep, the tray's leftovers and the header counts all read the unmatched lists, so marked songs drop out of them with no further change.
- **The screens:** the tray gains one lever, the review gains one collapsed group, and the hook gains two calls.

**Tech Stack:** React 19 (JavaScript, not TypeScript), Vite 8, Vitest 3, Oxlint, and `playwright-cli` (installed globally) for the layout check.

**Spec:** [docs/2026-10-11-no-match-design.md](../../2026-10-11-no-match-design.md). Read it in full before starting. It builds on [docs/2026-10-10-match-tray-design.md](../../2026-10-10-match-tray-design.md).

## Review Focus

The ways this most likely breaks for a real person, each pinned where it is owned:

1. **A book saved before marks existed,** or a hand-edited one with a half-formed mark, must load without a crash. A malformed mark is dropped, and every good decision is kept. Pinned in Task 1 (`loadMatchBook` tests).
2. **A song listed twice in a playlist** must leave the unmatched group in both copies when marked. Otherwise one copy keeps getting searched. Pinned in Task 1 (`setAsideMarked` test).
3. **A marked song later added to the other playlist** must pair, and must not stay hidden as marked (D38). Pinned in Task 1.
4. **A marked song that an earlier sweep found candidates for** must not come back as a proposed find. Pinned in Task 1.
5. **A Spotify local file** (no id) is marked under its URI. **A YouTube track with no id** cannot be marked, and pressing the lever does nothing rather than storing a broken entry. Pinned in Task 1 (`markKeysOf` tests).
6. **Long titles in the new group, at any width,** must stay in their columns. Pinned in Task 2 (the column check seeds a marked long YouTube title and opens the group at six widths).

export function markKeysOf(song) {
  if (song?.source === 'youtube') return song.id == null ? null : { spotifyKey: null, youtubeVideoId: song.id }
  const key = spotifyKeyOf(song)
  return key == null ? null : { spotifyKey: key, youtubeVideoId: null }

- [ ] **Step 5: Write `setAsideMarked`**

In `src/match/settleFound.js`, insert directly before `function certain(spotify, youtube, missingFrom) {`:

```js
/**
 * Songs left unmatched once the two playlists are paired, less those the
 * owner marked as not on the other service (no-match design §4). The marked
 * ones are set aside before settleFound runs, so no find is proposed for
 * them. A song that pairs from the playlists is not touched (D38).
 *
 * @returns the shape settlePairs returns, plus `markedSpotify` and `markedYoutube`
 */
export function setAsideMarked(settled, book) {
  const marks = book.filter((entry) => entry.verdict === 'none')
  const spotifyMarks = new Set(marks.map((entry) => entry.spotifyKey).filter((key) => key != null))
  const youtubeMarks = new Set(marks.map((entry) => entry.youtubeVideoId).filter((id) => id != null))
  const markedSpotify = (track) => spotifyMarks.has(spotifyKeyOf(track))
  const markedYoutube = (track) => youtubeMarks.has(track.id)
  return {
    ...settled,
    unmatchedSpotify: settled.unmatchedSpotify.filter((track) => !markedSpotify(track)),
    unmatchedYoutube: settled.unmatchedYoutube.filter((track) => !markedYoutube(track)),
    markedSpotify: settled.unmatchedSpotify.filter(markedSpotify),
    markedYoutube: settled.unmatchedYoutube.filter(markedYoutube),
  }
}

```

(`spotifyKeyOf` is already imported at the top of that file.)
